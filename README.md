# Vinter

Persönliches Markt- und Depot-Dashboard als Home-Assistant-Add-on. Nur lesen und rechnen: keine Bank-Zugangsdaten, keine Käufe oder Verkäufe, nur kostenlose öffentliche Datenquellen. Das Depot kommt aus einer selbst hochgeladenen CSV-Datei.

- Installation und Betrieb in Home Assistant: siehe [DOCS.md](DOCS.md)
- Läuft auf eigenem Port (8099) mit eigener Anmeldung, ohne Eintrag in der Seitenleiste
- API-Keys (alle kostenlos) trägt jeder Nutzer im Tool selbst ein, sie liegen nie im Repository
